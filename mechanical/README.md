# Механика Qulay — R1 с соединением C1

## Актуальные файлы

Для соединения рычага с валом применять **[C1](coupling_c1/README.md)**: цельный фланцевый вал, два штифта Ø3 и два прижимных винта M3. В этом выпуске определены геометрия, посадки, совместная обработка деталей, порядок сборки и критерии стендового контроля. Физические испытания ещё не выполнены.

**[PDF C1 с размерными чертежами](coupling_c1/generated/Qulay_C1_Lever_Shaft_Coupling.pdf)** · **[Все STEP/DXF, BOM и отчёты C1](coupling_c1/generated)**

Три актуальные компоновочные сборки с установленным соединением:

* [Qulay-C1-crossing.step](coupling_c1/generated/Qulay-C1-crossing.step) — обычное положение;
* [Qulay-C1-along-curb.step](coupling_c1/generated/Qulay-C1-along-curb.step) — проход вдоль бордюра;
* [Qulay-C1-datum-rail.step](coupling_c1/generated/Qulay-C1-datum-rail.step) — положение на направляющих.

C1 заменяет только соединение `A-xx / PS-xx`. Положение оси, магнита и платы сохранено; номинальный зазор фланец–плата соседнего канала теперь 1.0 мм. Старое значение 2.0 мм из R1 не переносить на C1. Подробности и бюджет отклонений — в документации C1 и `generated/verification.json`.

Новый источник — `coupling_c1/build.py`, использующий `revision_b.py` и `build.py`; чертежи собирает `coupling_c1/document.py`. Исторические каталоги `generated/` и `generated-r1/` сохранены и не являются сборками с C1. Общие руководства R1 читать вместе с [дополнением C1](../docs/REVISION_C1.md).

## Базовая компоновка и ограничения

Редактируемый параметрический источник: CadQuery/OpenCascade. Обменный формат: STEP с отдельными именованными и окрашенными телами. Эти STEP можно открыть в SolidWorks; родные файлы SLDASM/SLDPRT не выдаются за созданные, поскольку SolidWorks здесь не запускался.

Исторический `generated/` содержит три положения первоначальной компоновки, крупные CAD-проекции, PDF A3, реестры деталей и резки, DXF контура рычага 1:1 и отчёты валидности B-rep. Для разных положений опорные стойки представлены рабочей длиной, а не полным телескопическим механизмом. Поэтому три таблицы резки — состояния компоновки, не три перечня одновременно закупаемых стоек. Старый рычаг не заказывать для C1: у нового изменена головка.

Габаритная сборка НЕ является комплектом рабочих чертежей для заказа всей тележки. C1 закрывает передачу момента от рычага к валу, но не осевую фиксацию всего вала в корпусе, окончательное крепление магнита, рабочую пружину, механизмы фиксации высоты, стопоры, грязезащиту и весь проверенный маршрут жгутов. Для стендового изготовления согласовать требования и контроль из C1. В реестре у упрощённых элементов есть отметки.

Сборка с направляющими нужна не как украшение: высота рамы должна быть наблюдаема независимо от исследуемой поверхности. Направляющие также нельзя считать идеальными: измеряются их прямолинейность, прогиб под движущейся нагрузкой и биение жёстких опорных роликов. Обычные мягкие транспортные колёса без испытания не дают миллиметровой базы.

Габариты базовой тележки: наружная ширина по концам осей 870 мм, по колёсам 860 мм; колея 825 мм. База 700 мм, рама 840×800 мм. Измерительная полоса 750 мм между крайними осями, шаг 25 мм. Ширина реального доступного пути измеряется не шириной тележки, а несколькими геодезически привязанными проходами и границами препятствий.

Историческая пересборка R1: Python с `cadquery==2.8.0`, VTK, ezdxf, reportlab; системный DejaVuSans. `python mechanical/build.py`. Для C1 использовать отдельный генератор и workflow `.github/workflows/coupling-c1.yml`, а не только старый `build.py`. Часть размеров задаётся в `config/geometry.json`, часть фиксирована в эскизах QL-01; произвольная смена геометрии требует обновить и калибровочные данные, и исходные эскизы, а не только один JSON.
