# Механика QL-01

Редактируемый параметрический источник: `build.py` (CadQuery/OpenCascade). Обменный формат: STEP с отдельными именованными и окрашенными телами. Эти STEP можно открыть в SolidWorks; родные файлы SLDASM/SLDPRT не выдаются за созданные, поскольку SolidWorks здесь не запускался.

`generated/` содержит три положения одной компоновки, крупные CAD-проекции, PDF A3, реестры деталей и резки, DXF контура рычага 1:1 и отчёты валидности B-rep. Для разных положений опорные стойки представлены рабочей длиной, а не полным телескопическим механизмом. Поэтому три таблицы резки — состояния компоновки, не три перечня одновременно закупаемых стоек.

На текущей стадии допускается изготовить только согласованный стендовый образец отдельного канала. Габаритная сборка НЕ является комплектом рабочих чертежей для заказа всей тележки: посадки, крепёж, пружины, механизмы фиксации высоты, стопоры, грязезащита и весь проверенный маршрут жгутов требуют детализации. Внутри реестра у каждого упрощённого элемента есть отметка.

Сборка с направляющими нужна не как украшение: высота рамы должна быть наблюдаема независимо от исследуемой поверхности. Направляющие также нельзя считать идеальными: измеряются их прямолинейность, прогиб под движущейся нагрузкой и биение жёстких опорных роликов. Обычные мягкие транспортные колёса без испытания не дают миллиметровой базы.

Габариты: наружная ширина по концам осей 870 мм, по колёсам 860 мм; колея 825 мм. База 700 мм, рама 840×800 мм. Измерительная полоса 750 мм между крайними осями, шаг 25 мм. Ширина реального доступного пути измеряется не шириной тележки, а несколькими геодезически привязанными проходами и границами препятствий.

Пересборка: Python с `cadquery==2.8.0`, VTK, ezdxf, reportlab; системный DejaVuSans. `python mechanical/build.py`. Часть размеров задаётся в `config/geometry.json`, часть фиксирована в эскизах QL-01; произвольная смена геометрии требует обновить и калибровочные данные, и исходные эскизы, а не только один JSON.
