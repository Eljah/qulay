# Qulay / Кулай — контактный профилометр доступной среды

Редакция QL-01, 2026-10-02. Статус: инженерный прототип, НЕ утверждённое средство измерений и НЕ готовая рабочая документация для производства.

## Назначение

Тележка измеряет геометрию перехода «проезжая часть — бордюрный съезд — тротуар». Результат — исходные отсчёты, координатные профили, маски недостоверности и воспроизводимый протокол. Проверка геометрии не заменяет оценку сцепления, прочности, тактильных указателей, видимости, опасности движения и остальных требований доступности.

Два основных прохода:
1. CROSSING: поперёк бордюра, по направлению движения кресла. Продольный профиль требует независимой высотной базы.
2. ALONG_CURB: вдоль бордюра, часть роликов на тротуаре, часть на дороге. Одновременная разность высот наблюдаема без знания вертикального перемещения рамы.

## Что именно измеряется

Оси: X — направление прохода; Y — поперечная координата канала; Z — высота. Угол рычага — измеряемая величина, а НЕ координата Y и НЕ уклон поверхности. Для канала j:

`c_body = pivot_j + [L_j*cos(alpha_j), 0, L_j*sin(alpha_j)]`

`c_world = translation + R(yaw,pitch,roll) * c_body`

Здесь c — центр ролика. На гладком покрытии точка контакта `p = c - r*n`, где n — единичная нормаль поверхности. Простое вычитание радиуса по вертикали допустимо лишь на горизонтальном участке либо как явно обозначенная аппроксимация. Углы должны быть откалиброваны вместе с магнитом, подшипниками и рычагом. Смещение точки контакта по X меняется с углом: нельзя складывать все каналы в одну строку X без пересчёта.

### Ненаблюдаемость подъёма рамы

IMU измеряет ориентацию относительно гравитации в квазистатике, но не даёт точного перемещения рамы вверх-вниз. Наклон рамы + углы рычагов + пробег НЕ определяют продольный профиль однозначно. Двойное интегрирование ускорения не принято как миллиметровая высотная база.

Поэтому предусмотрены режимы DATUM_RAIL (тележка на независимых выставленных направляющих, положение измерительной кассеты зафиксировано), EXTERNAL_POSE (внешняя измерительная система с подтверждённой неопределённостью), FREE_ROLL (разведка, только локальные/поперечные геометрические величины). Без базы сервер не должен выдавать нормативный вывод по продольной высоте. GNSS — географическая привязка объекта, не миллиметровый Z.

### Бордюр — не просто очень крутой пандус

Ролик диаметром 40 мм не может гарантированно заехать на вертикальную ступень 150 мм. Не следует проталкивать тележку силой. При упоре/потере контакта фиксируется пропуск, кассета поднимается, выполняется отдельный проход сверху или ALONG_CURB. Нельзя интерполировать неизвестную вертикальную грань гладкой рампой. Дискретный ряд не видит все дефекты между дорожками; повторный проход со смещением 12.5 мм повышает поперечное покрытие, но не делает его непрерывным.

## Исходные проектные размеры, не нормативные значения

| Параметр | Значение |
|---|---:|
| Каналы | 31 |
| Шаг по Y | 25 мм |
| Расстояние крайних осей | 750 мм |
| Диаметр / ширина измерительного ролика | 40 / 12 мм |
| Длина рычага между осями | 240 мм |
| Рабочий угол рычага | от -70 до +20 градусов |
| Размах перемещения центра по Z | около 308 мм |
| Номинальная высота оси рычага над нижней площадкой | 220 мм |
| Наружная ширина тележки | 870 мм |
| Опорные колёса | 4 x диаметром 200 мм |
| База опорных колёс по X | 700 мм |
| Вертикальная перестановка кассеты | до 220 мм |
| Номинальная частота опроса | 100 Гц |
| Предельная скорость разведочного прохода | проектно 0.2 м/с |

Ширина кресел неодинакова; 870 мм — выбранный габарит прототипа, а не ссылка на «единственный стандарт кресла». Приёмка более широкой зоны требует нескольких привязанных перекрывающихся проходов. Один проход 750 мм не доказывает нормативную ширину всего съезда.

Рама — сварная профильная стальная труба 25x25x2 мм; измерительная поперечина — 40x40x2 мм. Независимые рычаги с подшипниками, торсионным возвратом, ограничителями и общей подъёмной гребёнкой. Регулируемые опорные узлы позволяют выровнять раму при проходе вдоль бордюра. Пружины обеспечивают контакт, но усилие и гистерезис необходимо измерять. Полость магнитного датчика отделяется от стальной рамы немагнитным кронштейном; взаимное влияние соседних магнитов проверяется на стенде.

## Электроника и связь

Raspberry Pi 4/совместимый Linux SBC: Java 21, локальный журнал, USB-накопитель, Wi-Fi, клиент сервера. Raspberry Pi Pico/RP2040: детерминированный опрос датчиков, одометр, аппаратные метки времени, USB CDC. Микроконтроллерная часть — C/Pico SDK; остальной прикладной комплекс — Java/Maven. Запуск Linux вместо измерительного MCU не обещает точного периода опроса.

31 x AS5048A, четыре SPI-цепочки 8+8+8+7, диагностические регистры, контроль чётности. Отдельное питание датчиков 3.3 В с запасом по току: не питать весь ряд от выхода Pico. Разрешение 14 бит не означает точность 0.022 градуса. Паспортная нелинейность AS5048A существенно выше одного отсчёта; обязательна индивидуальная многоточечная калибровка.

Опорный акселерометр/инклинометр ADXL355 через отдельный SPI, одометр квадратурный с отдельным измерительным колесом или кодером опорного колеса, контроль пробуксовки обратным проходом. Контакт/упор каждого канала не выводится только из красивой картинки: для полевой версии нужен проверенный датчик силы/контакта либо отдельная процедура обнаружения отрыва. До его реализации строгая приёмка блокируется.

Базовая связь: прибор самостоятельно выходит на сервер по Wi-Fi. Телефон может быть обычной точкой доступа, специальное мобильное приложение для передачи не требуется. Автономная сотовая связь — опциональный сертифицированный USB LTE-модем с SIM и своей антенной/питанием. Разработка собственной ВЧ-платы GSM в QL-01 не нужна.

## Программный комплекс

* `core`: строгий формат сырых отсчётов, геометрия, профили качества и проверка условий применимости.
* `server`: Spring Boot REST, устойчивое хранение, планы обследования, идемпотентная загрузка, проверка хеша, воспроизводимые отчёты.
* `desktop`: Swing; выбор каталога флеш-памяти, проверка и просмотр прохода, загрузка на сервер, получение плана и запись на флеш-память.
* `agent`: Raspberry Pi; запись USB CDC, завершение пакета атомарным переименованием, синхронизация после восстановления сети.
* `simulator`: синтетические поверхность/рама/отсчёты; гладкий съезд, завышенный уклон, поперечный уклон, бордюр, отрыв и отсутствие высотной базы.

Сырые данные неизменяемы. План, калибровка, версия алгоритма и профиль требований имеют идентификатор/хеш. Повторный расчёт с новыми нормами не меняет исходные измерения. Неполный проход не становится хорошим из-за фильтрации. Хеш защищает от случайного изменения, но сам по себе не доказывает личность оператора или подлинность измерения.

## Метрология и будущий ГОСТ

Разделить ТУ на прибор, методику измерений, правила оценки соответствия и процесс разработки национального стандарта. Изделие само по себе не «превращается в ГОСТ». Для применения в сфере государственного регулирования обеспечения единства измерений отдельно определить необходимость утверждения типа, поверки и применимые требования 102-ФЗ; обсуждать с ЦСМ до фиксации серийной конструкции.

Пороговые значения не зашиваются как универсальные «5 процентов для всего». Профиль правил содержит документ, редакцию, пункт, область применения, базу осреднения и правило решения с неопределённостью. В QL-01 демонстрационные пороги НЕ нормативные. Для верхнего предела T: соответствие при m+U<=T; несоответствие при m-U>T; иначе неопределённый результат. Недостающие данные имеют отдельный статус.

План верификации: плита, меры высоты, наклонная плоскость, ступени 5/10/15/20/150 мм, обратные проходы, смещение на полшага, температурные циклы, грязь, магнитное влияние, жёсткость рамы, испытание на отрыв, повторяемость разных операторов. Целевые показатели нельзя объявлять достигнутыми до испытаний.
