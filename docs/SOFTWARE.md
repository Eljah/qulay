# Программный комплекс QL-01

Java 21 + Maven. Spring Boot 3.5.16 зафиксирован как воспроизводимая базовая версия прототипа. До публичного промышленного развёртывания требуется переход на поддерживаемую на тот момент линию и аудит зависимостей; прототип по умолчанию слушает только localhost. Выбор версии не является обещанием актуальности её поддержки.

## Сборка

```
mvn -B verify
java -jar software/simulator/target/simulator-0.1.0.jar generated/demo
```

Linux/macOS:
```
export QULAY_TOKEN="$(openssl rand -hex 32)"
java -jar software/server/target/server-0.1.0.jar
```

Windows PowerShell: задайте собственный случайный токен не короче 24 символов в `$env:QULAY_TOKEN`, затем ту же команду `java -jar`. Никаких реальных секретов в репозитории нет. Для одиночной локальной демонстрации допустим явный `QULAY_DEV_MODE=true`, но не при сетевом доступе.

Веб-интерфейс: `http://127.0.0.1:8080/`. Токен хранится только в поле текущей страницы. Список, загрузка прохода, создание простого плана, отчёт. Полноценная карта и редактирование многообъектного плана пока не реализованы; REST принимает несколько объектов.

```
java -jar software/desktop/target/desktop-0.1.0.jar
java -jar software/agent/target/agent-0.1.0.jar sync generated/demo/surveys http://127.0.0.1:8080
```

Desktop: открыть JSON с парным SHA256, просмотреть профиль и причины блокировки, отправить на сервер, получить план по UUID и записать в каталог `QULAY/plans` на флеш-памяти, выгрузить координаты CSV. Сетевые операции не блокируют поток Swing.

## Реальная плата

```
java -jar software/agent/target/agent-0.1.0.jar capture /dev/ttyACM0 calibration.json plan.json 1000 /media/usb/QULAY/surveys
```

Нужен откалиброванный файл всех 31 каналов. Синтетический шаблон нельзя использовать для приёмки. Запись ведётся с сохранением сырых строк `.wire.partial`; лишь законченный проход получает JSON и SHA256. При обрыве остаётся неполный журнал, который не загружается автоматически. При подключённом, но переставшем передавать устройстве чтение блокирующее: остановка процесса сохраняет partial-журнал; watchdog/таймаут требуют доработки перед длительной полевой эксплуатацией.

Флаги неизвестного контакта на реальной плате НЕ превращаются в «контакт есть». Текущая прошивка не содержит доказанного канала контроля усилия. Реальные файлы пригодны для отладки сырых отсчётов, но не для положительного заключения. GNSS, внешняя высотная система, загрузка индивидуального LTE-модема и физические датчики контакта — аппаратные интеграционные этапы, не вымышленные реализованные драйверы.

## REST v1

* `GET /health` — без токена.
* `PUT/GET /api/v1/surveys/{uuid}`, `GET /api/v1/surveys`.
* `GET /api/v1/surveys/{uuid}/report`, `.../points.csv`.
* `PUT/GET /api/v1/plans/{uuid}`, `GET /api/v1/plans`.
* `GET /api/v1/rule-profiles` — пока только DEMO-ONLY-01.

Загрузка: точные UTF-8 байты JSON, `Content-Type: application/json`, `Authorization: Bearer ...`, `X-Content-SHA256: ...`. UUID неизменяем: те же байты — успешный дубликат, иные — HTTP 409. Ошибка SHA256 — 422. Ограничение тела 32 MiB, строгие размерности, конечность чисел, порядок времени, число кадров. В файл записываются принятые исходные байты, а не пересериализованная копия. Хранилище — локальные каталоги с атомарной записью; один процесс, не кластерная БД.

## Границы реализации

Есть работающий офлайн/HTTP-контур и геометрический симулятор. Нет аппаратных измерений, драйвера внешней геодезии, validated contact sensing, сертифицированной методики, роли администратора/оператора, цифровой подписи оператора, PostGIS и публичного многопользовательского сервиса. `acceptanceEligible` в QL-01 всегда блокируется причиной PROTOTYPE_METROLOGY_NOT_VALIDATED.

Радиус корректируется по локальной нормали только на гладких наблюдаемых участках при известном datum. FREE_ROLL использует явно маркированную вертикальную поправку радиуса. Края/пропуски не сглаживаются в пандус. Значение largestAdjacentLevelChangeMm — обнаруженная геометрическая разность, не автоматическое доказательство точной высоты вертикальной ступени.

`tools/e2e.py` поднимает настоящий JVM-сервер, проверяет авторизацию, SHA, повторы, конфликт, планы, agent sync, CSV и сохранение данных после перезапуска. Это не эмуляция RP2040 или электронной схемы.
