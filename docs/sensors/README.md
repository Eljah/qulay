# ЭМ-01 — датчики наклона, монтаж, жгуты и обработка

[Руководство PDF](generated/Qulay_Tilt_Sensors_Mounting_Wiring_Channels.pdf) — 29 страниц, включая 7 листов A3. Инженерная база: `097e60be99069dc5490a207dd999f34820637a1a`. Узел рычаг–вал — C1; явно разделены электроника R1/Q1 и R2/Q2.

Главные монтажные листы: 3 — паспортная цоколёвка AS5048A; 4 — вид в KiCad, установленная плата со стороны магнита и вид сзади; 8–10 — четыре банка и все 31 канала; 12–14 — разъёмы carrier/Pico и полный pinout ADXL355.

В AS5048A pin5 — TEST, который подключают к GND; pin14 — неиспользуемый PWM. Сеть GND и отметка NC в KiCad не являются паспортным названием ножки. Encoder.J1: 1=3V3, 2=GND, 3=CSn, 4=SCK, 5=DIN, 6=DOUT, шаг 2 мм. Выводы 11/12 IC соединены; подавать 5 В на готовую encoder-плату нельзя.

Разворот платы на 180° относится к установке всей платы в отверстия CAD, а не к пайке IC. В виде от магнита F.Cu направлена к −Y, отверстия выше оси, разъём ниже; J1 слева направо 6…1. Проверить по площадке 1 и прозвонке; корпус покупного кабельного разъёма ещё не закреплён спецификацией.

## Данные и проверки

* `generated/channel-map.csv` — j, суффикс CAD, банк/слот, координата Y, CS, ADC.
* `generated/encoder-harness.csv` — 186 конечных точек, сверенных с исходной таблицей. Междатчиковые соединения перечислены с обеих сторон; это не 186 уникальных проводов.
* `generated/commissioning-31-channels.csv` — пустой протокол наладки.
* `generated/calibration-DEMO.json` — синтетическая калибровка, НЕ для реального прибора.
* `generated/synthetic-Q1.wire`, `synthetic-Q2.wire` — по одному демонстрационному кадру; не готовый survey.
* `generated/java-checks.json` — 24 проверки поведения существующих Java-классов плюс 31 арифметическая проверка порядка сдвиговых слов. Не эмуляция платы.
* `generated/source-manifest.json`, `document-check.json` — хеши входов, база и контроль PDF.

## Пересборка

Python 3.12, зависимости из requirements.txt, системный DejaVu Sans; JDK 21. Нет обращения к аппаратуре и сервисам при сборке.

```sh
python docs/sensors/content.py
python docs/sensors/tools/prepare.py
sh docs/sensors/tools/test.sh
python docs/sensors/build.py
```

Все производственные схемы, прошивка и приложения сохранены без изменений. Документ не доказывает физическую точность, IP/ЭМС, нагрузочную способность жгута или готовность к приёмке. Исторические руководства не удаляются.
