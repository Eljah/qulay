# Один ролик — один измерительный канал

Самостоятельное пояснение К01 для QL-01.R1: **21 страница**, 20 листов A4 и один A3 с увеличенными векторными фрагментами исходной схемы KiCad.

[Открыть PDF R1](Qulay_One_Roller_Tilt_AS5048A_R1.pdf)

> **Дополнение C1:** указанная в PDF R1 незавершённость соединения рычага с валом больше не описывает актуальное конструктивное решение. Разработан цельный фланцевый вал с двумя установочными штифтами и двумя прижимными винтами. См. [конструкцию и сборку C1](../../mechanical/coupling_c1/README.md), [PDF с чертежами](../../mechanical/coupling_c1/generated/Qulay_C1_Lever_Shaft_Coupling.pdf) и [область замены R1 → C1](../REVISION_C1.md). Старый PDF оставлен как документ исходной ревизии, без изменения истории. Разработка конструкции не означает прохождения физических испытаний.

## Что объясняет документ

Различие вращения колеса, качания рычага и наклона рамы; какие части канала вращаются и какие неподвижны; магнитный принцип AS5048A; плата encoder и назначение каждого контакта; запрос/ответ SPI и чётность; цепочки 8+8+8+7; соответствие физических роликов, идентификаторов CAD и индексов Java; кадр Q1; преобразование к углу и координате; поправка радиуса; калибровка, диагностика и неизвестный контакт.

Отдельные расчётные примеры: `0xB800 → N=14336 → α=−45°`, координаты при L=240/H=220/r=20 мм, чувствительность по высоте и отличие дискретности от погрешности. Приложение А содержит параметры питания, тока, температуры, обновления угла, магнитного поля, центровки и зазора с оговорками из конкретной редакции паспорта.

## Что документ не обещает

В описанной исторической R1 ещё не было окончательного безлюфтового соединения рычага с валом. **Этот конструктивный вопрос теперь проработан в C1**; изготовление согласованной пары и фактический контроль люфта остаются отдельной проверкой. Осевая фиксация всего вала, окончательное крепление магнита, рабочая пружина и подтверждённый контроль контакта данным выпуском C1 не закрываются.

Сам факт наличия модели и схемы не означает, что физический канал уже изготовлен и откалиброван. Описанная здесь прошивка Q1 ждёт полные цепочки 8/8/8/7, а не автоматически определяет один отдельно подключённый датчик. Q1 выставляет CONTACT_UNKNOWN, поэтому исправный электронный угол не становится автоматически подтверждённой точкой покрытия.

Формулы, таблицы и цифровые проверки не являются метрологическими испытаниями. Исторический документ К01 не меняет конструкцию, прошивку и правила допуска к приёмке; изменение соединения задаётся отдельным комплектом C1.

## Источники и воспроизведение

Инженерный базовый коммит документа R1: `a72e3a0d45d8b01d22f80cbc825711bc627f5c7f`; ключевые файлы сверены со снимком `00f3a3f66a0dfe225c04cfb24890cf087a88f5a7`. Первичные внешние источники — официальный паспорт AS5048A/AS5048B v1-11 на сайте Infineon и документация Analog Devices. Ссылки и хеши входов находятся в PDF и `source-manifest.json`.

* `guide.json` — основной текст и данные листов.
* `appendix.json` — параметры микросхемы и магнитной установки; вставляется перед перечнем источников.
* `prepare_cad.py` — выделение настоящих тел одного канала из CAD R1. Разнесение деталей выполнено только для поясняющей иллюстрации, не для изменения монтажных координат.
* `build_guide.py` — сборка PDF R1, векторные поясняющие схемы и увеличенные фрагменты существующего экспорта KiCad. Электрические сети исходной схемы не изменяются. Генератор не включает механику C1.
* `examples.json`, `document-check.json` — расчётные примеры и проверка вёрстки; аппаратных испытаний они не подтверждают.

Из корня репозитория, в окружении Python 3.12 с CadQuery 2.8.0, ezdxf, reportlab, pymupdf, pillow и системным DejaVu Sans:

```sh
python docs/channel/prepare_cad.py
python docs/channel/build_guide.py
```

Workflow `.github/workflows/channel-note.yml` проверяет неизменность ключевых инженерных входов относительно базового коммита, собирает PDF и публикует результат только в `feature/qulay-prototype-20261002`. Полный сторонний паспорт и файлы шрифтов в комплект не включены.
