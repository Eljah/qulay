# Qulay QL-01.R1 — механическая часть и монтаж

[Открыть руководство PDF](QL01-R1-Mechanical-Installation.pdf)

37 страниц: 24 страницы A4 и 13 технических листов A3. Редакция документа D1, дата 03.10.2026. Инженерная база: `a72e3a0d45d8b01d22f80cbc825711bc627f5c7f`.

Руководство содержит состав деталей и резку труб, последовательность сборки рамы/кассеты/роликов, монтаж магнитов и encoder-плат, размещение carrier/Pico/SBC, прокладку жгутов, распиновку, карту всех 31 каналов, первичное включение, наладку, обслуживание и формы контроля.

Технические листы построены по существующим CAD-телам, DXF-контурам и сохранённым PCB. Две принципиальные схемы KiCad включены векторными страницами. Для разнесённого вида положения деталей искусственно изменены только в иллюстрации; рабочий осевой пакет приведён отдельно.

## Печать

Текст — A4; листы А01–А13 — A3. На листе А07 контур рычага дан 1:1: печатать 100%, без вписывания в страницу, и проверить контрольную линию 100 мм. Для изготовления приоритет имеют численные размеры и исходный DXF, а не измерение изображения.

## Статус

Предварительная документация для подготовки стендового образца. Посадки, часть креплений, пружины, стопоры, корпус и защита питания ещё требуют конструкторского решения и проверки. Контрольные остановки перечислены в руководстве. Ни PDF, ни успешные DRC/ERC не являются разрешением на серийное изготовление или подтверждением метрологической пригодности.

## Пересборка

Python 3.12, CadQuery 2.8.0, VTK, ezdxf, ReportLab, PyMuPDF, Pillow; системный DejaVuSans. Файлы шрифтов не включены в репозиторий.

```bash
python docs/manual/prepare_assets.py
python docs/manual/build_manual.py
```

`manual.md` — текст и директивы вставки таблиц; `build_manual.py` формирует страницы, извлекает PCB/DXF и создаёт `source-manifest.json` с SHA-256 инженерных источников. `prepare_assets.py` создаёт дополнительные проекции из неизменённого параметрического источника R1. `document-check.json` фиксирует число страниц и хеш PDF; это контроль документа, не испытание железа.

Workflow `Mechanical and installation manual` проверяет неизменность инженерных входов относительно базового коммита и публикует PDF в ту же feature-ветку без изменения main.
