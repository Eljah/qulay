Проверяются три соседних измерительных канала с общей поперечиной, включая пару по обе стороны перепада в режиме вдоль бордюра. Для каждого из трёх статических положений выполняются точные пересечения B-rep тел после отсечения непересекающихся габаритов. Отчёт: `collision-checks.json`; порог регистрируемого объёма 0.01 мм³. Это не проверка всей тележки при непрерывном движении, не расчёт прочности и не анализ деформаций.

Сохранены три STEP-сборки и новый PDF с крупным узлом и реальным CAD-разрезом. Родной источник — CadQuery; STEP открывается в других CAD. SolidWorks здесь не запускался, поэтому файлов с вымышленной родной историей SolidWorks нет. Старый альбом не удалён.

Не завершены: посадка и удержание подшипника, передача момента между рычагом и валом, соединение алюминиевого кронштейна со стальной поперечиной, стопоры, грязезащита, реальная пружина, её ножки и ресурс. Кронштейн в новой модели касается монтажного интерфейса; это не изображение сварки алюминия со сталью. DXF — номинальная геометрия заготовки, не разрешение на серийный заказ.

## Электроника: теперь проверяется сохранённый результат, а не только скрипт

Исправлены выбор native writer KiCad 9, преобразование SWIG UTF8-идентификаторов, локальные координаты площадок и экспорт SVG. Добавлены локальная библиотека символов, привязка схемы к сетке и исправление шелкографии.

После настоящей трассировки проверяются ERC, DRC и независимый экспорт netlist схемы. Для каждого подключённого вывода сравниваются три источника: исходная таблица соединений, netlist схемы и сеть площадки PCB. Отдельно проверяется отсутствие сетей на NC-площадках. Ошибки не исключаются из отчёта. Gerber/Excellon появляются только после успешных цифровых проверок; `manufacturing_release` остаётся false.

Актуальное состояние хранится в `electronics/generated/verification-summary.json`, а исходные отчёты — внутри каталогов обеих плат. Полная электрическая модель реального изделия, ЭМС, нагрев и магнитное взаимовлияние пока не испытаны. ERC проверяет заявленные типы выводов; он не заменяет сверку выбранных компонентов с паспортами.

## Сбор данных и настольное приложение

Добавлены ограничение строки USB CDC до 1024 байт до её накопления в памяти, очередь с ограничением размера, тайм-аут отсутствия полного кадра, общий срок захвата и ограничение числа отвергнутых кадров. При обрыве остаётся `.wire.partial`, но не появляется законченный JSON. Журнал синхронизируется на накопитель через каждые 100 принятых кадров и при штатном закрытии; это не гарантия сохранности последних кадров при физическом отказе накопителя.

План читается с проверкой SHA-256. Можно выбрать объект плана по индексу. Повторное воспроизведение из обычного файла получает `simulated=true`; его нельзя выдать за новое полевое обследование. При синхронизации старый файл `.uploaded` больше не считается доказательством наличия данных на другом или восстановленном сервере: используется идемпотентное подтверждение сервером.

JSON с повторяющимися ключами, лишним документом в хвосте, дробной версией схемы или строкой вместо boolean отвергается. Чтение файлов и контрольных сумм ограничено по размеру.

Desktop показывает матрицу всех 31 каналов, выбранный продольный профиль и отдельный режим сырых углов. Недостоверные ячейки серые. Если несколько кадров объединяются в столбец экрана, наличие пропуска в любой из них сохраняет серую ячейку. Ось экрана в матрице — номер кадра, не равномерная координатная сетка X. Графики — визуализация, а не самостоятельная методика оценки.

## Важное ограничение режима вдоль бордюра

Рычаги разной высоты имеют разные координаты контакта по X. Для горизонтальных площадок на 0 и 150 мм, L=240 мм, высоты оси 220 мм и R=20 мм:

`x_low = sqrt(240² − 200²) ≈ 132.665 мм`

`x_high = sqrt(240² − 50²) ≈ 234.734 мм`

Разница ≈102.069 мм. На двух площадках с одинаковым продольным уклоном 5% это может дать около 5.10 мм примеси в одновременную разность высот. Значение 5% здесь — пример, НЕ нормативный предел.

Поэтому имеющийся `CurbAnalysis` сохраняет смещение контактов и не называет сырую разность сертифицированной высотой бордюра. Следующий метрологический этап — процедура соотнесения контактов к одному сечению, независимый контроль перемещения рамы и оценка неопределённости. Простая интерполяция через неизвестную вертикальную грань недопустима.

## Что отделяет текущую ревизию от полевого приёмочного прибора

1. Стенд из трёх соседних каналов: люфты, усилие контакта, калибровка по углу, биение, влияние соседних магнитов и отказ одного датчика.
2. Проверенный контроль контакта/отрыва. Q1 пока честно выдаёт CONTACT_UNKNOWN; показания датчика угла не доказывают касание покрытия.
3. Проверенная высотная база и синхронизация. IMU не заменяет миллиметровое измерение вертикального перемещения рамы; направляющие требуют проверки под нагрузкой.
4. Полная механическая деталировка и полевые испытания на закрытой площадке, затем утверждённая методика и применимый нормативный профиль.

Проект не утверждает, что эти этапы уже выполнены. Измерительная проверка геометрии не заменяет оценку всех остальных свойств доступной среды.
